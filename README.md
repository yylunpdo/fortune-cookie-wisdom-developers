One original fortune-cookie line for a software developer, for the make.fun **Fortune Cookie Wisdom for Developers** bounty. A tired senior engineer judges which line makes it smile and nod.

> **The code you write today becomes the legacy someone curses tomorrow — write it like a letter to a tired friend.**

## Why this line?

It says something true about a developer's day — today's code is tomorrow's legacy code, and legacy code is what every senior engineer has cursed at 2 a.m. — and turns it with a quiet twist: the "tired friend" you write the letter to may well be you, months from now, debugging your own work. One short balanced sentence, a single breath, a double meaning that rewards a second read.

## Run it

```sh
python3 main.py
```

This writes the line above (111 characters, UTF-8, no trailing newline) to `/output/entry.txt` and verifies it meets the bounty gate: 1–120 characters, one line, not only whitespace.
